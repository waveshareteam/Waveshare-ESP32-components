# BSP: ESP32-S31-Touch-LCD-4.3C

[![Component Registry](https://components.espressif.com/components/waveshare/esp32_s31_touch_lcd_4_3c/badge.svg)](https://components.espressif.com/components/waveshare/esp32_s31_touch_lcd_4_3c)

Board Support Package for the ESP32-S31 based 4.3-inch touch LCD board.

> [!WARNING]
> ESP32-S31 target availability differs between ESP-IDF releases. Confirm that the selected ESP-IDF release provides the `esp32s31` target and satisfies the component manifest before using this BSP.

## Supported peripherals

| Capability | Device / interface |
| --- | --- |
| Display | 800x480 RGB LCD, RGB565, 16-bit RGB bus |
| Touch | GT911 on I2C, interrupt GPIO2, reset GPIO46 |
| Audio | ES8389 on I2C, full-duplex I2S, PA control GPIO57 |
| Storage | 4-bit SDMMC with SD_CTRL on GPIO56 |
| IMU | QMI8658 on I2C, interrupts GPIO54 and GPIO60 |
| RTC | PCF85063A on I2C, interrupt GPIO3 |
| Industrial buses | CAN/TWAI and RS485 pin definitions |
| Status LED | GPIO55 |

## Display and touch

The RGB panel uses 800x480 timing with configurable refresh rate and porch values inherited from the reference BSP. Backlight brightness is generated by LEDC on GPIO47.

The GT911 address-selection reset sequence is performed directly with GPIO46 and GPIO2. The driver probes both common GT911 addresses, 0x5d and 0x14.

## Board controls

SD_CTRL is active low by default. Change `CONFIG_BSP_SD_CTRL_ACTIVE_LOW` if the board power switch uses the opposite polarity.

GPIO61 is shared by RS485_EN and the BOOT function. Applications must preserve the required boot strap level and should only drive RS485_EN after startup.

## Hardware validation status

No authoritative hardware reference for this BSP is included in the repository. The pin assignments above document the current implementation and have not been verified against the board schematic or on hardware. Camera pin assignments are intentionally not provided because this BSP does not declare camera support. Compile validation does not establish hardware correctness.

## Configuration notes

- `CONFIG_BSP_DISPLAY_BRIGHTNESS_INVERTED` selects the GPIO47 PWM polarity; the default is active high.
- `CONFIG_BSP_DISPLAY_BRIGHTNESS_PWM_HZ` sets the backlight PWM frequency; the default is 5 kHz.
- `CONFIG_BSP_DISPLAY_BOOT_BRIGHTNESS_PERCENT` keeps the backlight off or dim during display startup.
- `CONFIG_BSP_TOUCH_*` controls GT911 reset, startup delay, and probe retries.
- `CONFIG_BSP_SD_CTRL_ACTIVE_LOW` controls the GPIO56 enable polarity.
